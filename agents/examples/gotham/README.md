# Example: a themed roster

An example themed roster, opt-in, not installed by default.

It is one complete cast: twenty-six agent definitions with voices and opinions about each other,
the workflow chains they were designed to run in (`CHAINS.md`), and an interview for rebuilding the
whole roster in a theme of your own (`RETHEME.md`). It is here to show what a themed team looks like,
not as the product. The default install ships three plain agents in `../../defs/`.

To try it, copy the files you want into your assistant's agent config. The paths inside these files
(`defs/`) mean "this folder". If you re-theme, regenerate the personas instead of find-and-replace.
